# Harsha — Animated Portfolio

Premium responsive portfolio built with Next.js, TypeScript, Tailwind CSS and Framer Motion.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Photo

Your uploaded photo is already included at:

`public/images/profile/harsha.jpg`

## Push to the existing GitHub repo

```bash
git clone https://github.com/saiharsha2512-tech/portfolioo.git
cd portfolioo
```

Copy/extract this project into that folder, then:

```bash
git add .
git commit -m "feat: build animated developer portfolio"
git push -u origin main
```
